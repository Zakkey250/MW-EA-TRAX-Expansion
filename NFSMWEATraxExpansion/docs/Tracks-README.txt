日本語
ゲーム終了中に、お手持ちのMP3・WAVをこのフォルダーにコピーしてください。サブフォルダーも使用できます。
次回起動時に生成画面が出たら完了を待ち、通知に従ってゲームを起動し直してください。
曲名・アーティスト名の指定は任意です。ひとつ上のREADME.mdに同名INIの作成例があります。

English
With the game closed, copy your MP3/WAV files into this folder. Subfolders are supported.
If generation starts on the next launch, wait for completion and restart as prompted.
Custom titles and artist names are optional. See README.md one folder above for a matching INI example.
