# MW EA TRAX Expansion 0.4.7

## 日本語

0.4.6で大きくなった再生キャッシュによる音楽の読み込み不具合を修正し、走行中の曲名HUDにアスペクト比補正を追加しました。0.4.6をご利用の方は更新をおすすめします。

### 修正・改善

- 追加EA TRAXとThe Run追跡BGMの生成形式を、非圧縮PCMからゲームが直接再生できるEA-XA圧縮へ変更しました。大容量キャッシュで追跡グループ8が無音になり、追跡終了後に通常曲へ戻れなくなる問題の原因となった、ネイティブファイル読み取りの上限超過を回避します。
- 統合キャッシュを2 GiB未満に制限しました。上限を超える場合は生成を停止して通知し、既存のキャッシュを保持します。追加曲を減らして再実行してください。
- 旧形式のキャッシュを検出して再生成します。既存の非圧縮The Run追跡データも、キャッシュ生成時に圧縮できます。
- The Run Pursuit Converterも圧縮出力に対応しました。コンバーター0.4.7にはMOD本体0.4.7が必要です。
- 走行中の曲名HUDを画面の縦横比に応じて左上へ補正します。メイン／ガレージメニューの配置は維持します。INIの `[Main]` → `HudAspectAssist=0` で補正を無効化できます（初期値は1）。

圧縮は非可逆です。元の音源は変更しません。検証環境では、追跡データは約505 MiBから136 MiB、統合キャッシュは約2.26 GiBから995 MiBに縮小しました。実際の容量は追加する音源によって異なります。

### ダウンロードと更新

- **NFSMWEATraxExpansion-v0.4.7.zip**：MOD本体。通常はこちらを使用してください。
- **TheRunPursuitConverter-v0.4.7.zip**：お手持ちのPC版The Runから追跡BGMを生成する任意のアプリです。
- **NFSMWEATraxExpansion-Source-v0.4.7.zip**：開発者向けソースとビルド手順です。

ゲームを終了し、既存のMODフォルダーと設定をバックアップしてから、本体ZIPの `scripts` をゲームフォルダーにコピーしてください。設定を変更している場合は、既存の `scripts/NFSMWEATraxExpansion/NFSMWEATraxExpansion.ini` を保持してください。HUD補正は設定項目がなくても有効です。`Tracks`、`UG2MusicSFx`、`Pursuit` の音源は保持してください。

次回起動時に必要なキャッシュが再生成されます。完了通知に従ってゲームを1回起動し直してください。既存のThe Run音源を使うだけなら、コンバーターの再実行は不要です。

音源、ゲーム実行ファイル、ASIローダーは同梱していません。The Run音源なしでもEA TRAX拡張を利用できます。UG2音源は従来どおり、お手持ちの `sdat.viv` から `MusicSFx.mpf` と `MusicSFx.mus` を取り出して配置してください。詳しくは同梱の日英導入ガイドをご覧ください。

### 確認内容

追加EA TRAX 42曲と追跡BGM 811ストリームを独立したデコーダーで検証し、再生時間と制御データの一致を確認しました。実機で音楽の不具合解消と3840×1600でのHUD補正を確認しています。他の解像度は座標計算テストで確認しています。

## English

This release fixes music-loading failures caused by oversized playback caches generated by 0.4.6 and adds aspect-ratio correction for the in-world song HUD. Updating from 0.4.6 is recommended.

### Fixes and improvements

- Added EA TRAX and The Run pursuit audio now use native EA-XA compression instead of uncompressed PCM. This avoids exceeding the native file-reading boundary that caused pursuit group 8 to become silent and prevented normal EA TRAX playback from resuming after pursuits with oversized caches.
- The combined cache is limited to less than 2 GiB. If it would exceed the limit, generation stops with a notification and preserves the existing cache. Reduce the number of added songs and try again.
- Old-format caches are detected and rebuilt. Existing uncompressed The Run pursuit data can also be compressed during cache generation.
- The Run Pursuit Converter now creates compressed output. Converter 0.4.7 requires the main MOD 0.4.7.
- The in-world song HUD is positioned toward the upper left according to the display aspect ratio. Main-menu and garage layouts are retained. Set `[Main]` → `HudAspectAssist=0` in the INI to disable this feature; the default is 1.

Compression is lossy; your original audio files are not modified. In the validation setup, pursuit data decreased from approximately 505 MiB to 136 MiB and the combined cache from 2.26 GiB to 995 MiB. Actual sizes depend on your music library.

### Downloads and updating

- **NFSMWEATraxExpansion-v0.4.7.zip**: the main MOD; choose this for normal installation.
- **TheRunPursuitConverter-v0.4.7.zip**: an optional application that generates pursuit music from your PC copy of The Run.
- **NFSMWEATraxExpansion-Source-v0.4.7.zip**: developer source and build instructions.

Close the game and back up your existing MOD folder and settings. Copy the main ZIP's `scripts` folder into the game folder. If you customized settings, retain your existing `scripts/NFSMWEATraxExpansion/NFSMWEATraxExpansion.ini`. HUD correction is enabled even when the new setting is absent. Keep your audio in `Tracks`, `UG2MusicSFx`, and `Pursuit`.

The next launch rebuilds the required cache. Follow the completion notice and restart the game once. You do not need to rerun the converter merely to keep using existing The Run pursuit audio.

No audio, game executable, or ASI loader is included. EA TRAX expansion works without The Run music. For UG2 music, continue extracting `MusicSFx.mpf` and `MusicSFx.mus` from your own `sdat.viv` and placing them as described in the included bilingual guide.

### Validation

All 42 added EA TRAX songs and 811 pursuit streams in the validation library were checked with an independent decoder, with matching durations and playback control data. Gameplay testing confirmed resolution of the music issues and HUD correction at 3840×1600. Other aspect ratios were covered by coordinate calculation tests.
