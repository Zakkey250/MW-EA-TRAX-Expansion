# NFSMW EA TRAX Expansion 0.4.7

## 日本語

Need for Speed Most Wanted（2005）のEA TRAXに、お手持ちのMP3・WAVやUnderground 2の楽曲を追加するMODです。The Runの追跡BGM8曲は、別配布のコンバーターとお手持ちのPC版The Runから追加できます。音源は同梱していません。

1. PC版MWの対応環境とASIローダーを用意してください。確認済みの環境、ローダーの入手先は[導入ガイド](scripts/NFSMWEATraxExpansion/README.md)をご覧ください。
2. ゲームを終了し、このパッケージの `scripts` フォルダーをゲームの実行ファイルと同じ場所にコピーしてください。
3. MP3・WAVを追加する場合は `scripts/NFSMWEATraxExpansion/Tracks` に置いてください。UG2の楽曲は、導入ガイドの手順で `MusicSFx.mpf` と `MusicSFx.mus` を取り出し、`UG2MusicSFx` に置きます。**`sdat.viv` をそのまま置いても読み込みません。** 音源の追加は任意です。
4. ゲームを起動してください。初回は「生成中」画面で待ちます。完了通知のOKでゲームを終了したら、もう一度起動してください。生成・完了通知はゲームの設定言語に合わせて表示されます。

詳しい音源の用意方法、設定、困ったときの確認先は[導入ガイド](scripts/NFSMWEATraxExpansion/README.md)に記載しています。通常は初期設定のままで使用できます。

## English

This MOD adds your MP3/WAV files and Underground 2 music to EA TRAX in Need for Speed Most Wanted (2005). Eight The Run pursuit scores can be added using the separate converter and your PC copy of The Run. Audio is not included.

1. Prepare a supported PC installation of MW and an ASI loader. See the [installation guide](scripts/NFSMWEATraxExpansion/README.md) for the verified environment and loader download.
2. Close the game. Copy this package's `scripts` folder into the folder containing the game executable.
3. To add MP3/WAV music, place it in `scripts/NFSMWEATraxExpansion/Tracks`. For UG2 music, follow the guide to extract `MusicSFx.mpf` and `MusicSFx.mus`, then place both in `UG2MusicSFx`. **Copying `sdat.viv` directly does not work.** Adding your own music is optional.
4. Start the game and wait for the first-time generation screen to finish. Click OK on the completion notice to close the game, then start it again. Generation and completion messages follow the game's configured language.

See the [installation guide](scripts/NFSMWEATraxExpansion/README.md) for audio preparation, settings and troubleshooting. The default settings are ready to use.
